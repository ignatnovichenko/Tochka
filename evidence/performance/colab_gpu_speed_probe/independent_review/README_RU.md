# Независимая проверка CPU / Colab T4 speed-probe

Проверены два реальных запроса Qwen2.5-7B-Instruct Q4_K_M на Tesla T4 в бесплатном Colab. Это одна задача FinQA (BLL/2007/page_35.pdf-1) в двух prompt-протоколах, direct и cot. Полный набор из 12 задач на GPU в этом архиве не представлен.

## Подтверждённые результаты

| Показатель | CPU | Colab T4 |
|---|---:|---:|
| Native decode, токенов/с | 5.09645 | 27.14943 |
| Native prefill, токенов/с | 20.82502 | 720.20799 |
| Сумма времени двух completion calls | 121.74837 с | 7.09202 с |
| Выходных токенов | 99 | 100 |
| Входных токенов | 2128 | 2128 |
| End-to-end output throughput | 0.81315 токена/с | 14.10036 токена/с |

Native decode ускорился примерно в 5.33 раза, prefill — в 34.58 раза. Полные вызовы оказались примерно в 17.17 раза короче, но выходные последовательности различаются, поэтому это описательное сравнение одинаковых запросов, а не строго одинаковой вычислительной траектории.

Все скорости пересчитаны как **сумма токенов / сумма соответствующего времени**, не среднее двух индивидуальных скоростей. GPU native counters: 100 decode tokens за 3683.318 мс; 2128 prefill tokens за 2954.702 мс. CPU: 99 за 19425.285 мс; 2128 за 102184.756 мс.

## Что проверено

- Архив NIR_Qwen7B_T4_py312_results.zip: 17626 байт, SHA-256 `af09dabc9942f310bc8b81d6487d02f0b972fe86776ead638b1506298868c172`. Все CRC корректны; каждый распакованный файл побайтно совпал с архивом.
- SHA-256 raw GPU records: `ddd242634da6b44b1fc667f11c02a01f55b463299ca0dde05df48daf352c0661`, совпадает с manifest. CPU raw records также проверены.
- Оба входных prompt и их SHA совпадают с CPU побайтно. Сходятся ID, model revision, Q4_K_M, seed42, max192, greedy parameters, ctx4096, batch/ubatch512 и четыре CPU-потока.
- Manifest весов совпадает с исходным CPU manifest. Исполненный GPU-скрипт перед загрузкой вычисляет SHA каждого локального shard и сравнивает с pinned official manifest. Сами многогигабайтные GPU-файлы в архив не включены и повторно здесь не хешировались.
- Native model_load.log показывает Tesla T4, `offloaded 29/29 layers to GPU`, CUDA KV/compute buffers. Это подтверждает реальный GPU offload, а не один лишь доступный torch.cuda.
- Счётчики prefill равны числу входных токенов. Счётчики и интервалы положительны, конечны; агрегированные скорости полностью совпадают с пересчётом из raw данных.
- В исполняемом коде видны сброс KV и native performance counters перед каждым вызовом. Отдельного warm-up нет.

## Точный runtime

GPU: Python3.12.3, официальный llama-cpp-python0.3.16-cu124 wheel, CUDA runtime12.4.127, cuBLAS12.4.5.8, Tesla T4 15360MiB, driver580.82.07. Wheel SHA указан в runtime_manifest и совпадает с официальным GitHub release digest. Установка завершилась exit0.

CPU: INTEL(R) XEON(R) PLATINUM 8573C; 9 видимых vCPU (os.cpu_count и affinity 0–8), в эксперименте четыре потока. Это не число физических ядер всего сервера; квота cgroup не доступна. Python3.12.14, llama-cpp-python0.3.16, локальная CPU-native сборка. CPU-хост Colab показывает Intel(R) Xeon(R) CPU @ 2.00GHz и 2 видимых vCPU, точный SKU не раскрыт. В Colab также задано n_threads=4 ради совпадения конфигурации; это oversubscription относительно двух vCPU. Отдельная проверка сохранена в ../cpu_hardware.json. Фактически меняются машина, CPU/CUDA backend и флаги сборки, а не только одна настройка.

Сборка из исходников для CUDA13 не является использованным backend. Рабочий GPU-result получен отдельным официальным CUDA12.4 wheel. По сообщению исполнителя, параллельная компиляция была приостановлена на время измерений, затем остановлена как ненужная.

## Ограничения

- Только два prompts одного задания, без повторений и доверительного интервала по скорости.
- GPU выдаёт другие ответы: direct 13 токенов на обоих устройствах, cot 87 на GPU против86 на CPU. Фиксированный seed/greedy не гарантирует побайтной одинаковости CPU/CUDA floating-point вычислений.
- Native decode исключает prefill и часть расходов host/sampling. Для ощущения скорости полного ответа важен отдельный completion wall time.
- Модель загружена до таймера запросов. Отдельного прогрева нет, OS cache не очищался; первый вызов может включать дополнительные расходы backend.
- Бесплатный T4 и его производительность не гарантируются для следующих сессий Colab.
- Это проверка скорости, не сравнение качества ответов. Исходные CPU canonical scores не пересчитывались и не заменялись GPU-probe.
