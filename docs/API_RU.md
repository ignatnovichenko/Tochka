# API-подключение Tochka 0.3.0

Tochka использует OpenAI-compatible Chat Completions без инструментов и stream. Секрет берётся из указанной переменной окружения, локального хранилища Tochka или выбранного подключения OpenCode Go и передаётся в Authorization Bearer. Внешний endpoint должен использовать HTTPS; для localhost разрешён HTTP. Redirect отключён. Ошибки не сохраняют тела HTTP-ответов или ключи. User-Agent — `Tochka/0.3.0`; для разговора формируется `x-opencode-session`.

Настройка — `tochka solver-add/judge-set --provider api --base-url ... --api-key-env ... --model ...`. Температура, max_tokens и timeout доступны через CLI. Ключ не вносится в JSON эксперимента. При 429 сохраняется срок ожидания; автоматического сетевого retry нет. При структурной ошибке судьи отдельно можно разрешить максимум 0–2 повторов, входящих в max_calls.

## Будущее подключение OpenCode Go

Официальная документация, проверенная 10.11.2026, указывает Chat Completions для моделей вроде `glm-5.3-flash`, `glm-5.3`, `minimax-m3.1-flash` на базе:

```
https://opencode.ai/inference/go/openai/v1
```

API ID не содержит CLI-префикса `opencode-go/`. Источник: [Go endpoints](https://opencode.ai/docs/console/go/#endpoints). Не путайте этот адрес с обычным pay-as-you-go endpoint. Здесь нет покупки, автоматического переключения тарифа или платного fallback.

Go описан провайдером как сервис для coding agents с типичным coding-трафиком. Tochka выполняет бизнес-бенчмарки: допустимость и пригодность этого сценария для Go стоит подтвердить у провайдера до покупки. Мы не подменяем идентификацию клиента. Совместимый транспорт реализован; фактическая работа на Go и доступные вашему аккаунту модели ещё не проверены. [Условия использования клиентами](https://opencode.ai/docs/console/go/#where-can-i-use-it).

Цена запроса из `usage.cost` сохраняется отдельно от токенов. При Go в пределах лимита это может быть 0, но **не означает бесплатную подписку**. Поле `opencode.estimated=true` остаётся оценкой, а не фактом списания. Включённый на аккаунте Extra Usage может расходовать баланс за пределами лимитов; Tochka не меняет эту настройку. [Cost API](https://opencode.ai/docs/console/api/inference/#cost), [Usage beyond limits](https://opencode.ai/docs/console/go/#usage-beyond-limits).

По предоставленным тарифам `--input-price-per-million` и `--output-price-per-million` программа может рассчитать оценочную стоимость при известных токенах. Она не выдаётся за списание и не удовлетворяет жёсткому требованию известной цены. Неизвестная стоимость остаётся null. На текущем этапе прямые Responses, Anthropic Messages, Gemini и streaming не реализованы; нужен Chat Completions endpoint или совместимый шлюз.


## Сохранённые ключи

`tochka keys` открывает список и меню добавления/удаления. Подкоманды: `list`, `add NAME`, `delete NAME`, `show NAME`. Добавление использует скрытый ввод; `add` по умолчанию настроен на OpenCode Go, для других API задайте `--base-url` и `--api-key-env`. Перезапись требует `--replace`. `show` выводит полное значение только в терминале.

Отсутствующий ключ при подтверждённом запуске запрашивается и сохраняется в `~/.config/tochka/credentials.json` (учитывается `XDG_CONFIG_HOME`). Это незашифрованный локальный файл с правами `0600`, папка `0700`; реализация хранения рассчитана на Linux/POSIX. Обновления атомарны и защищены блокировкой. Повреждённое хранилище не перезаписывается. В конфигурации эксперимента и отчётах секретов нет.

Сохранённый ключ используется только для совпадающих адреса API и имени переменной. Приоритет: введённый ключ текущей команды, переменная окружения, хранилище Tochka, совместимое подключение OpenCode Go. Последнее используется только для адреса Go и имени `OPENCODE_GO_API_KEY`. Удаление из Tochka не удаляет внешние источники и не отзывает ключ у провайдера. Без терминала используется уже доступный ключ; открытый ввод вместо скрытого не допускается.
