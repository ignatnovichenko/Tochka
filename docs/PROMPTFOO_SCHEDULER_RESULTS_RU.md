Время здесь — длительность вызовов API, без очереди и запуска worker; сумма ответа и проверки не равна длительности всего параллельного эксперимента. Сравнивать эти времена напрямую со старыми измерениями, включавшими запуск процесса, нельзя.

В последних двух группах по одному дополнительному запросу исправления структуры оценки. Такие исправления явные и входят в бюджет; скрытые транспортные повторы отключены. Учтено 37 048 токенов по данным API.

Калибровка: **4/4** размеченных примера обработаны, совпадение pass/fail и наличия критической ошибки — **100%**. Разметка авторская, синтетическая; это не независимая сертификация судьи.

Исправления исполнялись отдельными матрицами. Кэш и дополнительная база результатов Promptfoo отключены. Ускорение относительно прежнего движка этим опытом не измерялось.

## Предшествующая попытка с HTTP 429

[`runs/promptfoo_scheduler_20261111`](../runs/promptfoo_scheduler_20261111) сохранён полностью. При параллельности 4 два запроса GPT 6 Luna получили HTTP 429; два уже запущенных запроса Qwen завершились успешно. Оставшиеся 8 заданий, включая калибровку, были отклонены локально без запроса API из-за cooldown. Итого 4 попытки API, а не 12: журнал содержит также локально отклонённые задания.

Cooldown консервативно общий для адреса и ключа, поэтому остановил и другие модели. Ошибка Luna не доказывает недоступность Qwen или GLM. После истечения сохранённого интервала выполнен отдельный успешный прогон выше без Luna. Неизвестные оценки остались `null`; подходящих конфигураций в неудачной попытке нет. Стоимость двух неудачных запросов неизвестна; их нельзя считать бесплатными.

В первой попытке использовалась промежуточная сборка: локальным пропускам ещё записывалось нулевое время. В итоговом коде отсутствие вызова оставляет время неизвестным. Исходные артефакты не исправлялись задним числом; время из этой попытки не следует использовать для сравнения.
