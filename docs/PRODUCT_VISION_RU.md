# Продуктовое направление Tochka

Зафиксировано по решению пользователя 11 ноября 2026 года. Это целевое направление развития; описанные возможности не означают готовность текущего MVP.

## Универсальность для бизнеса

Tochka проектируется для разнообразных операционных и бизнес-процессов разных компаний. Один демонстрационный сценарий может ограничивать пилот, но не продуктовое направление и архитектуру.

У каждой компании свой набор процессов, требований и оптимальных конфигураций моделей. Компания может одновременно использовать десять и более моделей: разные модели и настройки подходят для разных типов задач. Цель — подобрать портфель конфигураций под процессы компании, а не одну лучшую модель на всю компанию.

## Маршрутизатор для AI-агентов

Tochka используется AI-агентами как сервис подбора и маршрутизации моделей. Агент может обратиться к Tochka, когда встречает новый тип задачи, операционный или бизнес-процесс, для которого ещё нет проверенного маршрута.

Целевой сценарий:

1. Агент обнаруживает новый тип процесса и передаёт его в Tochka для оценки с необходимыми задачами, контекстом, критериями и ограничениями.
2. Tochka проводит сравнительные прогоны подходящих конфигураций, измеряя качество, время и доступную стоимость.
3. На основании результатов определяется подходящая конфигурация или набор конфигураций для этого типа задач в данной компании.
4. Результат подбора сохраняется как маршрут; последующие задачи этого типа направляются через него без повторного полного сравнения каждый раз.

Таким образом, текущий экспериментальный стенд становится основой функции освоения новых процессов: агент инициирует оценку, Tochka собирает основания для выбора, а затем использует накопленные результаты для маршрутизации.

## Вопросы для дальнейшего проектирования

Нужно отдельно определить обнаружение новых типов процессов, источники эталонов и критериев, бюджет экспериментальных вызовов, условия включения маршрута, поведение при недостатке данных и основания для повторной оценки. Эти механизмы пока не зафиксированы решением пользователя.
